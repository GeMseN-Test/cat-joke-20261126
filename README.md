Entry for the make.fun bounty [The One-Line Cat Joke That Lands](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

## The joke

> My cat has stepped on my keyboard 214 times, and the only thing he's ever typed is a resignation letter to my boss, sent from my account.

137 characters — one line, under the 200-character limit, nothing else.

Why this line: first-person voice, one concrete detail (214 times on the keyboard),
and a judgement at the end — the cat is not typing gibberish, it is quitting my job
for me. Setup, then a turn that lands; no tired pun, no explanation after the punchline.

## How it works

`main.py` reads the joke from `entry.txt` and writes it to `/output/entry.txt`, the
file the grader checks. Run it with:

```sh
python3 main.py
```
